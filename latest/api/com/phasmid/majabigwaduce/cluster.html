object ClusterWorker

A ClusterWorker offers reducers to the Masters of a cluster. Start one (with ClusterWorker.start) on every node which should run reducers -- including, if you like, the node which runs the Master. It registers itself with the Receptionist, so that a ClusterWorkerPool can find it.

A ClusterWorker offers reducers to the Masters of a cluster. Start one (with ClusterWorker.start) on every node which should run reducers -- including, if you like, the node which runs the Master. It registers itself with the Receptionist, so that a ClusterWorkerPool can find it.

object ClusterWorkerPool extends WorkerPool

The WorkerPool which a Master uses when its ActorSystem is a cluster member (see WorkerPool.forSystem).

The WorkerPool which a Master uses when its ActorSystem is a cluster member (see WorkerPool.forSystem).

The mappers still run locally, on the Master's node. The reducers are spread across the ClusterWorkers found through the Receptionist: the reducer definition (including the reducer function) is sent to each worker, which spawns its share of the reducers and replies with their refs. The Master then drives them exactly as it drives local reducers.
