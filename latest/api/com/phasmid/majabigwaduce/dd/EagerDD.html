EagerDD

case class EagerDD[K, V](kVs: Seq[(K, V)])(implicit ec: ExecutionContext) extends BaseDD[K, V], HasEvaluatedMap[K, V]

Case Class which implements DataDefinition[K, V] eagerly and which is based on a Map[K,V]. NOTE: this type serves as the appropriate result of evaluating a lazy DD. In that respect it is the equivalent of the array which is created when invoking collect on an RDD in Spark.
