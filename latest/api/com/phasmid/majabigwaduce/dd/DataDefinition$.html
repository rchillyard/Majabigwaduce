DataDefinition

com.phasmid.majabigwaduce.dd.DataDefinition
See theDataDefinition companion trait
object DataDefinition

Represents a singleton object that provides definitions or metadata for data-related functionalities.

This object is designed to encapsulate the structure and behavior associated with defining, managing, or interpreting data schemas or specifications.

It can be used to centralize data definitions, facilitate consistency across data-related processes, and support extensible data handling operations.

def shutdown(): Unit

Terminates the ActorSystem backing this object's shared DDContext.

Terminates the ActorSystem backing this object's shared DDContext.

DataDefinition's actor context is a JVM-wide singleton, created lazily the first time this object is touched, and there was previously no way to explicitly tear it down. Any short-lived process (or test/benchmark) which embeds DataDefinition should call this once it's done, so the underlying ActorSystem doesn't keep the JVM alive indefinitely.
