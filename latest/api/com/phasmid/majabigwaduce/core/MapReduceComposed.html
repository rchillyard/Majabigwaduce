case class MapReduceComposed[T, K1, V1, K2, V2](f1: MapReduce[T, K1, V1], f2: Seq[(K1, V1)] => Future[Map[K2, V2]])(implicit ec: ExecutionContext) extends MapReduce[T, K2, V2]

A composition MapReduce class which represents a MapReduce "pipeline" with two stages.

output value type

Value parameters

an instance of MapReduce which will become the first of two stages of the resulting MapReduce instance .

f2

an ASync[Seq[(K1, V1)], Map[K2, V2] instance (functionally equivalent to MapReduce) which will become the second of the two stages.
