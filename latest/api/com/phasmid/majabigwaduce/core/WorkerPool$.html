def forSystem(system: ActorSystem[_]): WorkerPool

Chooses the WorkerPool for a Master running in system: the pool named by majabigwaduce.cluster.worker-pool if system is a cluster member (and that key is set, i.e. the majabigwaduce-cluster module is on the classpath); otherwise LocalWorkerPool.
