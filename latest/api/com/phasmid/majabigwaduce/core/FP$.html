def asFuture[X](xy: => Try[X]): Future[X]

Converts a lazy Try[X] into a Future[X].

Converts a lazy Try[X] into a Future[X].

If the Try is a Success, the resulting Future will be successfully completed with the same value. If the Try is a Failure, the resulting Future will be failed with the same exception.

Type parameters

X

the type of the value contained within the Try.

Value parameters

a lazy computation producing a Try[X] instance, which may either be Success containing a value or Failure containing an exception.

Attributes

Returns

a Future[X] that is completed based on the outcome of the provided Try.
